# MyLibraryforOtzaria

מאגר זה מאפשר ליצור DB אישי לאוצריא בלי להתקין שום דבר ובלי ידע טכני. אתם מעלים את הספרים שלכם למבנה התיקיות, וגיטהאב יוצר את ה-DB בשבילכם.

## איך משתמשים

1. לוחצים על **Fork** (בפינה הימנית העליונה) כדי ליצור עותק אישי של המאגר בחשבון שלכם.
2. מוסיפים את הספרים שלכם לתיקייה המתאימה במבנה. בתוך התיקייה לוחצים **Add file ← Upload files** וגוררים את הקבצים. אפשר גם להעלות תיקיות שלמות.
3. לוחצים **Commit changes**.
4. מחכים כמה דקות. בלשונית **Actions** אפשר לראות שהיצירה רצה, ובסיומה עם וי ירוק.
5. נכנסים ללשונית **Releases** (בצד ימין של דף המאגר), ומורידים את קובץ ה-DB מהגרסה האחרונה.

בכל שינוי בתוכן התיקיות ה-DB נבנה מחדש אוטומטית. אפשר גם להריץ ידנית: **Actions ← Generate Smart Index DB ← Run workflow**.

## חשוב לדעת

- קבצי `a.gs` שבתיקיות נועדו רק לשמור על התיקיות ריקות (גיט לא שומר תיקיות ריקות). הם לא נכללים ב-DB, ואין צורך למחוק אותם.
- קובצי README וכל קובץ בסיומת GS לא נכללים ב-DB.
- שינויים בקבצים שבתיקיית השורש עצמה (כמו קובץ זה) לא מפעילים בנייה מחדש. רק שינויים בתוך התיקיות.
- שמות קבצים ותיקיות בעברית נתמכים.

## העלאה כקובץ ZIP

אפשר להעלות קובץ בשם `A.zip` לשורש המאגר, עם מבנה תיקיות בתוכו. הוא יחולץ אוטומטית, יימחק, וה-DB יתעדכן.
