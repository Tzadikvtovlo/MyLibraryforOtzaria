# MyLibraryforOtzaria

מאגר זה מאפשר ליצור DB אישי לאוצריא בלי להתקין שום דבר ובלי ידע טכני. אתם מעלים את הספרים שלכם (קבצי TXT) למבנה התיקיות, וגיטהאב יוצר את ה-DB בשבילכם.

## איך משתמשים

1. לוחצים על **Fork** (בפינה הימנית העליונה) כדי ליצור עותק אישי של המאגר בחשבון שלכם.
2. **חד-פעמי:** נכנסים ללשונית **Actions** בעותק שלכם ולוחצים על **I understand my workflows, go ahead and enable them**. בעותקים משוכפלים גיטהאב מכבה כברירת מחדל את ההרצה האוטומטית, ובלי זה שום DB לא ייווצר.
3. מוסיפים את הספרים לתיקייה המתאימה במבנה. בתוך התיקייה לוחצים **Add file ← Upload files** וגוררים את הקבצים (ראו "העלאה" למטה).
4. לוחצים **Commit changes**.
5. מחכים כמה דקות. בלשונית **Actions** אפשר לראות שהיצירה רצה, ובסיומה מופיע וי ירוק.
6. נכנסים ל-**Releases** (בצד ימין של דף המאגר), ומורידים את קובץ ה-DB מהגרסה **latest**. זו תמיד אותה כתובת, והקובץ מתעדכן בכל בנייה.

בכל שינוי בתוכן התיקיות ה-DB נבנה מחדש אוטומטית. אפשר גם להריץ ידנית: **Actions ← Generate Otzaria DB ← Run workflow**.

## העלאה

העלאה דרך הדפדפן מוגבלת ל-25MB לקובץ ול-100 קבצים בכל פעם. לקבצים גדולים או רבים מעלים ZIP.

### העלאה כקובץ ZIP

1. אורזים ל-ZIP את התיקיות והספרים **בדיוק במבנה שבו הם צריכים להיות במאגר**. למשל, ZIP שמכיל `תלמוד בבלי/ברכות/ברכות.txt` יתמקם בתיקייה `תלמוד בבלי/ברכות`.
2. מעלים את ה-ZIP לשורש המאגר (**Add file ← Upload files**, בלי להיכנס לתיקייה). שם הקובץ לא משנה, ואפשר להעלות כמה ZIP יחד.
3. גיטהאב מחלץ אותו אוטומטית, מסדר את הקבצים לפי המבנה שבתוכו ומוחק את ה-ZIP. אחר כך ה-DB נבנה מחדש.

שימו לב: המערכת לא מנחשת לאן לשים קבצים. המיקום נקבע רק לפי נתיבי התיקיות בתוך ה-ZIP. קובץ שנמצא בשורש ה-ZIP יישאר בשורש המאגר, ואינו נכלל ב-DB. ZIP שהורד מגיטהאב עצמו (**Code ← Download ZIP**) מטופל נכון, כולל תיקיית העטיפה שלו.

## מה נכנס ל-DB

- קבצי **TXT** בלבד, מתוך תיקיות. מבנה התיקיות הופך לקטגוריות בספרייה, ושם הקובץ הוא שם הספר.
- כותרות בפורמט `<h1>`–`<h6>` בתוך הקבצים הופכות לתוכן עניינים.
- **קישורים אוטומטיים:** ל-DB נוצרים קישורים בין פירושים לספרי הבסיס לפי מבנה הכותרות, בעזרת מנוע [מחולל הקישורים](https://github.com/YairDaniel11/Otzariya_Link_Maker): פירושים על הש"ס הבבלי (דף), תרגומים וראשונים על התנ"ך (פרק), הירושלמי, הגהות אשרי ועוד. הקישורים מאומתים מול ה-DB הרשמי של אוצריא, ולכן ה-workflow מוריד אותו בזמן הריצה (כמה GB, נשמר ב-cache), והבנייה הראשונה איטית יותר. ספר שאין לו כלל מתאים נכנס בלי קישורים.
- **קישורים משלכם:** אפשר להעלות תיקייה `קבצי קישורים וסדר הדורות` עם קבצי `links.csv` (`קישורים/NN/links.csv`) ו-`דורות.csv`. ספרים שיש להם קישורים כאלה לא מקבלים קישורים אוטומטיים.
- קובצי README, קבצי GS וכל קובץ שאינו TXT לא נכללים.
- קבצים שבשורש המאגר, כמו קובץ זה, לא נכללים, ושינוי בהם לא מפעיל בנייה מחדש.
